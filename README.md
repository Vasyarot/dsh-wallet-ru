# dsh-plugin-wallet-ru

Баланс DeepSeek, тариф, расход сеанса и траты за неделю в доке композера:

```
Не пик 12 ч 45 мин   ·   Баланс: $0.83 · ¥12.50 · бонус $1.00   ·   Сессия: 12,3 тыс. ток · $0.04
    ↑ подсказка: цены       ↑ подсказка: $, ¥, баллы                    ↑ клик: траты за 7 дней
```

## Что показывает

| Элемент | Значение |
|---|---|
| Тариф | `Не пик` зелёным, `Пик` красным |
| Остаток | сколько осталось до смены тарифа (`12 ч 45 мин`, `48 мин`, `5 ч`) |
| Баланс | доллары всегда и первыми, подчёркнуты и кликабельны — ведут на страницу пополнения; **юани и бонусные баллы — только если их больше нуля** |
| Сессия | токены за сеанс и его стоимость, подчёркнуты и кликабельны |

Валюты приходят с платформы как `normal_wallets` и `bonus_wallets` (каждая пара
`{currency, balance}`). Хост отдаёт их целиком, клиент печатает USD, затем
недолларовые кошельки (`¥` для CNY) и бонусные баллы с пометкой «бонус».

## Подсказки при наведении

У каждого блока чипа своя подсказка — общая длинная строка убрана.

**«Пик / Не пик»** — только цены за миллион токенов, действующий тариф первым,
второй ниже:

```
Пик (сейчас)
ввод $0.28 · кэш $0.028 · вывод $0.42 за 1M токенов

Не пик
ввод $0.14 · кэш $0.014 · вывод $0.21 за 1M токенов
```

Вне пика строки меняются местами: `Не пик (сейчас)` сверху, `Пик` снизу.

**Баланс** — текущий баланс в долларах, баланс в юанях и бонусные баллы:

```
Текущий баланс: $0.83
В юанях: ¥12.50
Бонусные баллы: $1.00
```

Если юаней нет — `В юанях: нет`; если бонусов нет — `Бонусные баллы: 0`.

**Сессия** — подсказки нет; клик открывает график трат.

## Клики

- **Сумма баланса** — открывает пополнение **внутри приложения**, штатным окном
  просмотра платформы: оверлей на всё окно с полосой «‹ Назад · Пополнение
  баланса · Перезагрузить · В браузере», под полосой — нативная страница
  `platform.deepseek.com/top_up`. Автоматического перехода во внешний браузер
  нет — только по кнопке «В браузере».

  **Почему оверлей в `shell.overlay`, а не полоса под композером.** Окно
  платформы регистрируется в том же устойчивом хосте, куда штатный раздел
  «Аккаунт» кладёт свои страницы (`PlatformOverlay` из `ui-settings-account`).
  Раньше окно жило в доке композера: любая перерисовка дока могла снести
  нативную вьюху, и окно «открывалось», а рисовать было уже нечему. Оверлей
  ещё и сдвигает содержимое под заголовок окна Windows
  (`--dsh-windows-titlebar-height`), поэтому страница не залезает под системные
  кнопки, а его область отдаётся в main как `getBoundingClientRect()` и едет за
  окном через `ResizeObserver`.

  **Белая страница — это проверка CloudFront.** `platform.deepseek.com` закрыт
  AWS WAF: ответ — `202` с `x-amzn-waf-action: challenge`, то есть пустая
  страница на 2.5 КБ с проверочным скриптом. Скрипт грузится с
  `*.token.awswaf.com`, и на этом канале его TLS-соединение рвётся
  (`ERR_SSL_PROTOCOL_ERROR`), проверка не отрабатывает — остаётся белый экран.
  Вьюха при этом считает, что страница загрузилась, поэтому снаружи отличить её
  от настоящей нельзя.

  Поэтому в полосе **всегда** есть «Перезагрузить»: один клик — новая попытка,
  обычно страница появляется с первого-второго раза. Если `open()` падает с
  сетевой ошибкой, плагин сам повторяет попытку до трёх раз с паузой 0.8–2.2 с.
  Слепой повтор после *успешного* открытия не делается: он с равной
  вероятностью выбросил бы уже загруженную страницу.

- **Расход за сеанс** — открывает окно над чипом с графиком трат за последние
  7 дней. Закрывается по Escape, клику мимо и повторному клику по кнопке.

## Траты за 7 дней

Окно 300 px: заголовок, итог, строка деталей и семь столбцов.

- Высота столбца — стоимость дня; день без запросов остаётся тонкой серой
  полоской, поэтому на графике видно паузы.
- Под столбцами — короткие дни недели (`пн`, `вт`, …).
- Наведение на столбец подсвечивает его и показывает
  `29.10 · $4.68 · 309,9 млн токенов · 1300 запросов`; без наведения строка
  показывает сумму токенов и число запросов за неделю.
- Итог недели — в правом верхнем углу, дублируется в нижней строке вместе с
  общим числом токенов.
- Дни приходят с хоста уже заполненными: 7 записей, включая нулевые, по
  возрастанию даты.

## Цены и данные

- Токены сеанса — проекция `tokenUsage` от слота (`useProjection`):
  ввод без кэша + чтение кэша + запись кэша + вывод. Если оболочка не отдала
  проекцию, вместо чисел стоит `—`.
- Деньги — по текущему тарифу, доллары за миллион: ввод `$0.14`, кэш `$0.014`,
  вывод `$0.21` вне пика; в пик ×2. Запись в кэш считается по цене ввода.
  Цены для подсказки берутся из ответа `/wallet-ru` (`perMillion`), поэтому
  изменение тарифов на платформе подхватится без правки клиента.
- Недельная статистика — хост читает журналы сессий (`sessionPersistence`),
  складывает usage по датам и считает каждый запрос по тарифу своего времени.

## Баланс

Два источника, по порядку:

1. **Обычный вход в аккаунт** — `deepseekAccount.getBalance()`, ключ API не нужен.
2. **Ключ API** — `GET https://api.deepseek.com/user/balance` с `DEEPSEEK_API_KEY`
   из credentials или окружения.

Сумма берётся из долларового кошелька; если его нет — `$—`, причина в подсказке.

## Установка

Плагин рассчитан на DSH **0.2.1-rc.5** и новее (`engines.dsh` в `package.json`).

**Web-профиль:**

```powershell
dsh plugin --profile web add github:Vasyarot/dsh-wallet-ru
```

CLI добавит пакет в зависимости профиля и в `dsh.profile.bundles`. После установки
перезапустите DSH.

**Desktop-профиль.** Командная строка им не управляет — отвечает
`profile "desktop" is managed exclusively by the Electron application`. Ставится
в самом приложении:

1. боковая панель → **Плагины** (Plugins);
2. **Добавить плагин** (Add plugin) → вставьте `github:Vasyarot/dsh-wallet-ru`
   или абсолютный путь к папке плагина;
3. **Установить**, затем включите появившийся бандл;
4. перезапустите приложение.

**Удаление:** `dsh plugin --profile web remove dsh-plugin-wallet-ru`; в desktop —
карточка плагина в том же разделе **Плагины** → **Удалить**.

## Проверка без приложения

```powershell
node tools/smoke.mjs       # подсказки, геометрия графика, разметка чипа
node tools/route-test.mjs  # маршруты /wallet-ru и /wallet-ru/usage на фейковом хосте
```

`tools/smoke.mjs` рендерит чип через `react-dom/server`; `react` ищется в
переменной `DSH_TEST_NODE_MODULES`, затем в соседней папке `Voice/node_modules`.

## Файлы

- `index.js` — маршруты `GET /wallet-ru` и `GET /wallet-ru/usage?days=7`.
- `client.js` — чип, подсказки и окно трат с графиком.
- `cordis.patch.yml` — строка `wallet-ru` для дерева профиля.
- `tools/` — локальные проверки (в пакет не входят).
